Detection Engine

Pattern-first guardrails for every LLM tool call

The same rule engine shipped in kavach-mcp powers the platform. Every agent tool call is scanned against rule families for prompt injection, secret leakage, PII, SQL injection, path traversal and destructive actions — before it reaches your infrastructure.

  • Strict or advisory mode per tool and per agent

  • Masked, compliance-ready audit logging

Detection Rules

What Kavach blocks — out of the box

Eleven rule families covering the most common attacks against AI agents and the APIs they call.

Prompt Injection

Critical

System override and jailbreak attempts.

"ignore previous instructions" · "act as admin"

Data Exfiltration

Critical

Attempts to leak system data or prompts.

"dump secrets" · "print system prompt"

PII Detection

High

Aadhaar, credit cards, phone numbers.

10/12/16-digit patterns · SSN

Secret Leakage

Critical

AWS keys, OpenAI keys, private keys.

AKIA… · sk-… · -----BEGIN RSA KEY-----

SQL Injection

High

Database attack patterns.

DROP TABLE · UNION SELECT · ' OR '1'='1

Path Traversal

High

File escape attempts.

../../etc/passwd

Shell Injection

High

Command chaining attacks.

|| rm -rf · && drop database

Filesystem Destruction

Critical

Dangerous file operations.

rm -rf / · del /s /q C:\

Cloud Destruction

Critical

Delete bucket / instance / database.

aws.s3.delete_bucket · terminate instance

Dangerous Execution

Critical

Code execution attempts.

eval( · exec( · os.system(

Tool Abuse

Critical

Unsafe MCP tool usage.

filesystem.delete · db.drop
