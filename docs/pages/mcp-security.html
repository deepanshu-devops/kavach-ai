The Model Context Protocol is the connective tissue of the agentic era — and it hands agents direct access to files, databases and clouds. Kavach puts a guard in front of every tool your agents can reach.

The problem

Agents are one prompt away from production

A single LLM tool call can delete a bucket, dump a database or steal a secret. Static config scans never see it — Kavach intercepts at runtime.

Tool inventory

Know every registered tool

Auto-discover tools from FastMCP, LangChain and custom servers. Track schemas, auth scope and which agents can call them.

Call-time guardrails

Block the blast radius

sensitive_tools patterns — exact or wildcard — scope protection to aws.*, filesystem.* and beyond. Strict mode raises, advisory mode logs.

Audit trail

Compliance-ready logging

Every blocked call is recorded with rule, severity and masked payload — safe to ship to Datadog, Kafka, ELK or CloudWatch.

Why MCP is the new attack surface

Your LLMs can call anything. Kavach decides what they're allowed to.

MCP standardizes how models reach your files, databases and clouds. That same reach is the attack surface. Kavach wraps the protocol's tool-call boundary with the same detection engine used by cloud security teams.

  • Wildcard tool scoping: aws.*, filesystem.delete
  • Wildcard rule matching with per-tool severity
  • Pluggable logging with secret masking
  • Sync API + FastMCP async middleware
